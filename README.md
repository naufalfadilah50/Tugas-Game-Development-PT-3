# Game Menara Hanoi (Tower of Hanoi)

Tugas mata kuliah Game Development Semester 5. Ini adalah game edukasi klasik Menara Hanoi versi anak-anak yang dibuat pakai HTML, CSS, dan JavaScript murni. Tampilannya sengaja dibikin warna-warni biar menarik.

## Cara Main
1. Misi utamanya memindahkan seluruh tumpukan cincin dari **Tiang A** ke **Tiang C**.
2. Aturan utamanya: **Cincin kecil nggak boleh ada di bawah cincin besar**.
3. Cara interaksinya tinggal klik tiang tempat cincin berada buat ngambil, terus klik tiang tujuan buat mindahin.

## Penjelasan File Project
- `index.html` : Kerangka utama tampilan game di browser.
- `style.css` : Desain tata letak (layout) dan warna-warni cincin biar ramah anak.
- `script.js` : Logika game, ngatur perpindahan array, sama validasi aturan main supaya cincin gak bisa asal tumpuk.
